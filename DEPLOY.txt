Portfolio Studio - final viewport and text-editing fixes

Extract this ZIP. Replace index.html in your EDITOR GitHub Pages publishing folder, with .nojekyll alongside it. After deployment finishes, press Ctrl+Shift+R to load the new editor.

For local use, open index.html in Chrome or Edge. Choose your portfolio website ZIP, not this editor ZIP.

Includes a fitted preview with Top control, formatted text-part editing, Back/Forward/Parent inspector arrows, Ctrl+Z undo and Ctrl+Y redo. Dark/light mode and By Gopinath credits remain included.

The editor does not publish changes or modify the original imported ZIP. Export website creates a separate updated website ZIP. README.md contains usage details; VALIDATION.md records checks and compatibility limits.
